What Changes When Mode Is Hidden
  • Inventory and purchase screens hide Non-GST options while the mode is hidden.
  • Backend posting blocks Non-GST stock bucket and Non-GST purchase treatment while hidden.
  • GST flow remains available either way.
This is UI hiding plus backend enforcement. Even direct API requests cannot post Non-GST stock when the mode is hidden.
